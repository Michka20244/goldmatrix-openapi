# Privacy Policy

Last updated: September 2026

GoldMatrix API provides financial market data and analytical services.

## Information We Process

When this API is used through ChatGPT Actions, we may receive:

- Requested market symbol
- Timeframe
- Analysis parameters
- Technical request metadata (IP address, timestamps, request identifiers)
- Error logs

We do not intentionally collect:

- Name
- Email address
- Passwords
- Payment information

## How We Use Information

We use the information solely to:

- Process API requests
- Generate market analysis
- Improve service reliability
- Monitor performance
- Prevent abuse

## Data Retention

Technical logs may be retained for security, debugging, and operational purposes for a limited time.

## Third Parties

Market data may be obtained from third-party financial data providers.

## Security

We implement reasonable technical and organizational measures to protect the service and processed data.
